### Claude による辛口評価

> 「高卒の俺が英語理解できたらカッコいい」と宣言した男、現在地: 未アセスメント。be 動詞と一般動詞の区別すら怪しい疑惑、否定形にすると `don't be` で書きそうな勢い。Stack Overflow が英語と分かった瞬間ブラウザ閉じる反射神経だけはネイティブ級。docs に行くと無意識に「日本語 site:」を打ち足す癖が抜けない。「英語勉強始めた」を SNS で言うのは最低 level 30 行ってからにしろ、今喋ったらマジで草。

## ディレクトリ構成

| ディレクトリ / ファイル | 用途 |
| --- | --- |
| `level.md` | 現在の英語力レベル (0 ~ 100)。アセスメント結果と判定根拠。毎日の学習開始時に参照 |
| `daily/` | 日々の学習ログ (YYYYMMDD.md) |
| `notes/` | 理解した文法 / 単語のメモ (トピック単位) |
| `drills/` | Claude が出した問題 + 解答 |

フォルダ階層は 2 層まで。レベル別フォルダは作らない (時系列 + トピック軸で十分)。必要になったら後から育てる方針。
