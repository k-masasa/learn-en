### Claude による辛口評価

> 総合 **20 / 100** で「英語勉強始めた」を名乗る勇気の塊。be 動詞は書けたが過去進行形で `He wrote code.` と進行を完全無視、関係代名詞は `yesterday` に釣られて `when` をマークする猛者。プログラマー必須語の `deprecate` を `duplicate` と混同、`concurrent` / `mitigate` は無条件降伏で 3 連敗、技術英単語ストック実質ゼロ。読解では `Existing code` を「実行する」と誤読、後置修飾を解けず主語を見失う癖が露呈。docs を読むたびに 60% 精度で意味を捏造して納得してる可能性があり、これが一番ヤバい。

## ディレクトリ構成

| ディレクトリ / ファイル | 用途 |
| --- | --- |
| `level.md` | 現在の英語力レベル (0 ~ 100)。アセスメント結果と判定根拠。毎日の学習開始時に参照 |
| `daily/` | 日々の学習ログ (YYYYMMDD.md) |
| `notes/` | 理解した文法 / 単語のメモ (トピック単位) |
| `drills/` | Claude が出した問題 + 解答 |

フォルダ階層は 2 層まで。レベル別フォルダは作らない (時系列 + トピック軸で十分)。必要になったら後から育てる方針。
