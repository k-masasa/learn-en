### Claude による辛口評価

> 総合 **15 / 100**、初回アセスメント全領域完了で順当に下方修正。受動態 / 進行形の骨格 (be + p.p., be + ~ing) は組めるが、`This bug is fixed on latest version.` で時制 / 前置詞 / 冠詞を 3 連続で外し、`He is reviewing codes now.` で `code` を可算名詞扱いして暗号レビュアーに変身。極めつけは「これは私が昨日書いたコードです」を `I wrote the code on yesterday.` と書き、英語の「This is ~」の枠組みを丸ごと飛ばして勝手に主語を自分にすり替える癖が露呈。読解 Q9 で `Existing code using this method` の後置修飾を解けず、作文 Q12 でも `the code I wrote yesterday` の後置修飾を出せず、**読解と作文で同じ穴に同じ顔で落ちる**一貫性は天才的。`deprecate` を `duplicate` と混同して `concurrent` / `mitigate` に無条件降伏する技術英単語ゼロストックも継続中、docs を雰囲気で意味捏造して納得してる可能性は依然として高い。

## ディレクトリ構成

| ディレクトリ / ファイル | 用途 |
| --- | --- |
| `level.md` | 現在の英語力レベル (0 ~ 100)。アセスメント結果と判定根拠。毎日の学習開始時に参照 |
| `daily/` | 日々の学習ログ (YYYYMMDD.md) |
| `notes/` | 理解した文法 / 単語のメモ (トピック単位) |
| `drills/` | Claude が出した問題 + 解答 |

フォルダ階層は 2 層まで。レベル別フォルダは作らない (時系列 + トピック軸で十分)。必要になったら後から育てる方針。
